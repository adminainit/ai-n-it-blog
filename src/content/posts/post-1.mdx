## Introduction

Astro is a modern web framework that helps you build faster websites. It does this by rendering your UI components to HTML on the server, and only sending the essential JavaScript to the browser. 

This approach, known as "Islands Architecture", allows you to use your favorite UI frameworks like React, Vue, or Svelte, without sacrificing performance.

### Why combine Astro and React?

While Astro's built-in component syntax is powerful, there are times when you need the complex state management and rich ecosystem that React provides. 

*   **Interactive Components:** React is perfect for highly interactive components like image carousels, complex forms, or real-time data visualizations.
*   **Existing Codebases:** If you already have a library of React components, you can easily drop them into an Astro project.
*   **Rich Ecosystem:** Tap into the vast ecosystem of React libraries for things like animations (Framer Motion) or complex data fetching.

Here is an example of some code in MDX:

```jsx
import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Clicked {count} times
    </button>
  );
}
```

Astro makes it incredibly easy to use these technologies together, giving you the best of both worlds.
