## Why Animate?

Animations are not just about making things look pretty. When used correctly, they improve the user experience by:

*   Providing feedback (e.g., a button press)
*   Guiding the user's attention
*   Smoothing out state transitions

## Framer Motion Basics

Framer Motion is a production-ready motion library for React. It makes complex animations incredibly simple.

The core of Framer Motion is the `<motion.div>` (or any other HTML element prefixed with `motion.`). 

### The `animate` prop

The simplest way to animate an element is by passing an object to the `animate` prop. When the values in this object change, Framer Motion will automatically animate the transition.

```jsx
import { motion } from "framer-motion"

export const MyComponent = () => (
  <motion.div
    animate={{ x: 100, opacity: 1 }}
    initial={{ x: 0, opacity: 0 }}
    transition={{ duration: 0.5 }}
  />
)
```

With just a few lines of code, you can create fluid, professional-feeling interfaces that delight your users.
